| 2026-11-07 | 合図を待つのを `main` への push とマージに絞り、トピックブランチへの push は合図不要にする | 確認待ちで作業が気付かぬ間に止まるのを避けるため。オーナーが全リポジトリ共通の方針として決めた。止める対象はデプロイにつながる既定ブランチだけとする |

| 2026-11-07 | `ask` への追加は打ち止めにし、`allow` からトピックブランチへの `git push` 8 件を外す（オーナー判断） | 末尾が自由な `allow` は、後ろに別の引数を続ければ `main` の更新や別ブランチの削除まで確認なしで通しうる（セキュリティレビューの指摘）。**残る限界**: 文字列の照合では push 先を網羅できない。`allow` を外した形は `auto` の分類器の判定になり、rebase 後の `--force-with-lease` は止まることがある。確実に止める手段は `main` への PR 必須化だけだが、§1.1 の直コミットと両立しないので入れない |

## 1. 画面一覧と遷移

タブは無い。プール（01）が唯一の根で、他はすべてそこから開く。

```
01 プール（根）
 ├─ 02 登録シート ──（02b 新しいカテゴリ／行き先ダイアログ）
 ├─ 06 品目編集シート（行の長押し）
 ├─ 03 買い物開始シート ──▶ 04 買い物モード ──（05 気づいたものを足すシート）
 └─ 07 設定 ──▶ 08 テーマ／09 カテゴリの管理／09 行き先の管理／ライセンス
                                └─ 09b 編集シート（行の長押し）
```

| 番号 | 名前 | 型 | 入り方 |
|---|---|---|---|
| 01 | プール | 画面（根） | 起動時 |
| 02 | 登録シート | ボトムシート | 01 のアプリバーの＋ |
| 02b | 新しいカテゴリ／行き先ダイアログ | ダイアログ | 02・06 のチップ「＋ 新しいカテゴリ」「＋ 新しい行き先」、09 の「＋ カテゴリを追加」「＋ 行き先を追加」 |
| 03 | 買い物開始シート | ボトムシート | 01 の「買い物を始める」 |
| 04 | 買い物モード | 画面 | 03 の行タップ |
| 05 | 気づいたものを足すシート | ボトムシート | 04 の破線行 |
| 06 | 品目編集シート | ボトムシート | 01 の行の長押し |
| 07 | 設定 | 画面 | 01 のアプリバーの⚙ |
| 08 | テーマ | 画面 | 07 の「テーマ」 |
| 09 | カテゴリの管理／行き先の管理 | 画面（同型 2 枚） | 07 の各行 |
| 09b | カテゴリ／行き先の編集シート | ボトムシート | 09 の行の長押し |

ライセンス画面は既存の AboutLibraries 画面を流用する（07 から開く。デザイン刷新の対象外でよい）。

## 2. 操作の共通作法

- **行タップ＝最頻で取り消し可能な操作**。プールではカゴ出し入れ、モードではチェックの付け外し
- **行の長押し＝編集シート**。01・09 で共通。**04（買い物モード）では長押し編集は無効**
- FAB は置かない。品目の登録はアプリバーの＋から
- 削除は常に編集シート（06・09b）の中に置き、確認ダイアログで影響を件数提示する
- シートはスクリム・グリップ付きのボトムシート。スクリムタップ・下スワイプ・システムバックで閉じる（保存されていない入力は破棄）
- ダイアログ表示中のシステムバックはダイアログだけを閉じる
- スナックバーは「画面に変化が見えない操作」の完了通知にだけ使う（現時点では 05 の思い出しの追加のみ）
- 日付表示は一覧では「前回 M/D」（未購入は「前回 —」）、編集シートでは「最終購入日: YYYY-MM-DD」

### 名前入力の共通仕様

品目・カテゴリ・行き先の名前入力欄（02・02b・06・09b・05 の検索欄からの登録）に共通。検証則の正は [14](./14_データモデル定義書.md) §5。

- 31 文字目以降は入力できない（打ち切り）
- 確定操作（登録・作成・保存）時にトリムして検証し、エラーは入力欄の下に赤字で出す。シート・ダイアログは閉じない
- エラー文言: 空は「名前を入力してください」、重複は「同じ名前がすでにあります」、上限超えは「30 文字以内で入力してください」
- **エラーは必ず文言を持つ。** 打ち切りがあるので上限超えは通常起きないが、**起きない想定のエラーにも文言を置く**——文言の無いエラーは、赤枠だけが出て理由が分からない状態になる。今後足すエラーも同じ

## 3. UI に出す語彙

「登録＝品目を作る」「追加＝買うものに入れる」の書き分けが軸。実装語彙（品目・アイテム・カゴ・プール・モード）は UI 文言に出さない。

| 概念 | UI に出す語 | UI に出さない実装語彙 |
|---|---|---|
| 品目 1 つ | 名詞を出さない（動詞・実名・「もの」で語る） | 品目・Item・アイテム |
| 品目を新しく作る | 登録 | insert |
| 買うものに入れる | 追加・追加済み・未追加 | カゴ・basket・InBasket |
| 常駐する全品目の集合 | 名詞を出さない（「全 n 件」） | プール・pool |
| 店でチェックする状態 | 買い物中・チェック | 買い物モード・mode |
| 品目の分類タグ | カテゴリ | Category |
| 買う店 | 行き先 | destination |
| 行き先のない品目 | どこでも買えるもの | 行き先なし・null |

## 4. 画面定義

### 01 プール

唯一の常駐画面。全品目の一覧と管理、買い物の起点。

- **アプリバー**: ブランド名「Re-Buy」＋総数「全 n 件」。右に＋（→ 02）と⚙（→ 07）
- **絞り込みチップ列**: 先頭「すべて」、続いてカテゴリ（手動並び順）、行き先（手動並び順）、末尾「🏬 どこでも」。カテゴリ・行き先を各 0〜1 個選べて AND 結合、「すべて」で両方解除。**選択中のチップをもう一度タップするとそのチップだけ解除**（片方だけ外すのに「すべて」から選び直さなくてよい）。行き先チップは厳密（「🏬 スーパー」はスーパーの品目だけ、「🏬 どこでも」は行き先なしだけ）。🏬 はシステムが表示時に前置する絵文字で、名前の一部ではない
- **一覧**: 全品目を登録順（古い順）で。行＝名前＋カテゴリタグ＋行き先タグ＋「前回 M/D」＋トグル。**カテゴリ・行き先が無いものはそのタグを出さない**（「どこでも買えるもの」は行では名乗らない）。カゴ入りは行の色とトグルの ✓ で示し、**一覧の上には寄せない**（トグルで行が飛ばないように）
- **行タップ**: カゴ出し入れのトグル
- **行の長押し**: 06 を開く
- **下部 CTA**: 「買い物を始める」＋カゴ件数バッジ。カゴ 0 件のときは無効
- **空状態**（品目 0 件）: 「まだ何も登録されていません」＋「右上の ＋ から登録できます」
- **絞り込み結果 0 件**: 「この条件のものはありません」
- 残論点: 長押しの発見性をどう補うか（初回ヒントなど）。FB で拾う

### 02 登録シート

- タイトル「新しく登録」。名前入力欄（プレースホルダ「名前」・自動フォーカス）＋「カテゴリ（任意）」「行き先（任意）」のチップ列。チップは各 0〜1 個選択、末尾に「＋ 新しいカテゴリ」「＋ 新しい行き先」（→ 02b）
- **「登録」**: 検証 → 登録してシートを閉じる。登録直後の品目はカゴに入れない
- **「続けて登録」**: 検証 → 登録し、名前だけクリアしてチップ選択を保持したまま開いたまま
- 新規登録の品目は一覧の末尾（登録順）に現れる

### 02b 新しいカテゴリ／行き先ダイアログ

- タイトル「新しいカテゴリ」または「新しい行き先」。名前入力欄だけの小ダイアログ。「作成」「キャンセル」
- 「作成」で検証 → 即登録され、呼び出し元のチップ列に**選択済み**で現れる（09 から開いた場合は一覧の末尾に現れる）。並び順は末尾
- 検証則は管理画面（09）と同一

### 03 買い物開始シート

出発前ビュー。カゴの中身を行き先別に確認し、行き先を選んでモードに入る。

- タイトル「今日はどこへ？」＋補足「行き先を選ぶと、買い物が始まります」
- **内訳行**: カゴ内に品目を持つ行き先だけを手動並び順で。行＝行き先名＋プレビュー＋件数。プレビューは表示順（登録順）の先頭 2 件固定の実名（「牛乳・食パン」。「など」は付けない）。件数は「n＋m 件」（n＝その行き先のカゴ内件数、m＝どこでも買えるもののカゴ内件数。m が 0 なら「n 件」）
- **行タップ**: その行き先の 04 へ（シートは閉じる）
- **全件モード**: カゴに行き先付きの品目が 1 件も無いとき、内訳の代わりに「n 件で開始」の 1 行のみを出す。タップで行き先なしの 04（タイトル「買い物中」）へ
- どこでも買えるものを独立したグループとしては出さない（件数の「＋m」でのみ表現）

### 04 買い物モード

店内のチェック画面。

- **アプリバー**: ←＋タイトル「◯◯で買い物中」（全件モードは「買い物中」）＋進捗「x / n」（チェック済み／一覧総数）
- **一覧**: カゴ内の「選んだ行き先の品目（登録順）」→ 区切りラベル「どこでも買えるもの」→ どこでも買えるもの（登録順）。全件モードは区切りなしの単一リスト（登録順）。一覧の末尾に破線行「＋ 気づいたものを足す」（→ 05）
- **行タップ**: チェックの付け外し。チェック済みは ✓＋取り消し線で示し、**行の位置は動かさない**
- **行の長押し**: 無効
- **下部 CTA「買い物を終了する」**: チェック済みの品目だけをプールへ戻し（最終購入日を今日で記録）、01 へ戻る。未チェックはカゴに残る。確認ダイアログは出さない
- **←・システムバック**: 確認ダイアログ「買い物を途中でやめますか？」＋「チェックした内容は残ります。あとから再開できます。」＋「やめる」「続ける」。「やめる」で 01 へ（チェック状態は保持）。05 表示中のバックはシートを閉じるだけ
- アプリを閉じてもチェックは残り、01 の「買い物を始める」→ 03 から再入場すれば続きから

### 05 気づいたものを足すシート

モード中の割り込み追加。**どの経路も 1 件でシートは自動で閉じる。**

- タイトル「気づいたものを足す」＋検索欄（プレースホルダ「名前で探す…」・自動フォーカス）
- **初期表示（入力が空）**: セクション「未追加のものから選ぶ」＝今の行き先の未追加分（登録順）→ 区切り「どこでも買えるもの」＝どこでもの未追加分（登録順）
- **入力中**: トリムした入力文字列の単純部分一致で全品目を検索（ひらがな・カタカナの同一視はしない）。セクション構成は上から
  1. 「未追加のものから選ぶ」: 今の行き先＋どこでも買えるもののヒット。区切り「どこでも買えるもの」も維持
  2. 「他の行き先から」: それ以外の行き先のヒット
  3. 「＋ この名前で登録する」ボタン（固定文言）: 入力が空白のみでない間、常に末尾に表示
  - 空のセクションは見出しごと出さない。追加済みのヒットは所属セクションに「追加済み」表示（タップ無効）で出す
- **未追加の行のタップ**: 今の行き先・どこでもの品目 → カゴ入りし、今の一覧に現れて閉じる。**他の行き先の品目 → その行き先のカゴに入るだけ**で今の一覧には現れず、スナックバー「◯◯に追加しました」（◯◯＝行き先名）で通知して閉じる（「あの店で買うものを思い出した」用）
- **「＋ この名前で登録する」**: 検証（§2）→ 行き先＝今の店・カテゴリなしで登録し、即カゴ入りして閉じる。キーボードの確定では登録しない。全件モードでは行き先なしで登録する
- **全件モード**: 「今の行き先」を持たないため、初期表示は未追加の全品目（登録順・区切りなし）、検索でも「他の行き先から」枠は使わずすべて 1 に出す

### 06 品目編集シート

- 01 の行の長押しで開く。タイトル＝品目名。02 と同じ型で、名前入力欄＋カテゴリ・行き先のチップ列（「なし」チップと「＋ 新しい〜」を含む）＋「最終購入日: YYYY-MM-DD」（未購入は「最終購入日: —」）
- **「保存」**: 検証 → 反映して閉じる（重複判定から自分自身は除く）
- **「「◯◯」を削除…」**: 確認ダイアログ「「◯◯」を削除しますか？」＋「削除すると元に戻せません。」＋「削除する」「キャンセル」。削除で閉じて 01 へ

### 07 設定

- 行: 「カテゴリの管理」「行き先の管理」「テーマ」（現在のテーマ名を右端に表示）「ライセンス」。最下部にバージョン「Re-Buy x.y.z」
- 利用規約・プライバシーポリシー・問い合わせはリリース前まで**行ごと出さない**

### 08 テーマ

- 「若葉」「藍」「柿」の 3 択。行＝色見本＋名前＋選択中の ✓。タップで**即時反映**（保存ボタンなし）。既定は藍
- 明暗（ライト／ダーク）は OS 設定に追従し、アプリ内に切り替えは置かない。選択は端末内に保存

### 09 カテゴリの管理／行き先の管理

同型の 2 画面。

- **一覧**: 手動並び順。行＝ドラッグハンドル ≡＋名前。ドラッグで並び替え、離した時点で保存
- **末尾の破線行**「＋ カテゴリを追加」「＋ 行き先を追加」: 02b を開く。作成された行は末尾に現れる
- **行の長押し**: 09b を開く
- **空状態**: 破線行だけを出す

### 09b カテゴリ／行き先の編集シート

- 06 と同じ型。タイトル＝現在の名前、名前入力欄＋「保存」
- **「「◯◯」を削除…」**: 確認ダイアログで影響を件数提示。行き先は「「◯◯」を削除しますか？」＋「紐づく n 件は「どこでも買えるもの」になります。」、カテゴリは「紐づく n 件はカテゴリなしになります。」（n＝0 のときは「紐づくものはありません。」）。「削除する」「キャンセル」。**品目は消えない**

## 5. デザイン

素の Material から離れ、「台所のメモ」寄りの面構えにする。

- **タイポグラフィ**: 見出し・CTA は丸ゴシック（Zen Maru Gothic の Bold 1 ウェイトを同梱。約 3.8MB）、本文は OS 既定のゴシックに任せる。**本文用のフォントは同梱しない**（配布サイズを倍にするだけの効きが無い）
- **形状**: 角丸を大きめに取る（行 13dp・CTA 15dp・シート上部 22dp を目安）
- **数字**: 件数・日付・進捗は等幅数字（tabular-nums）

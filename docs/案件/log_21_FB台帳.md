# FB 台帳 決定ログ

- [FB 台帳](./21_FB台帳.md) の運用ルールを「なぜそう定めたか」を日付順に積む。本文は現在のルールだけを持つ

| 日付 | 決定 | 理由 |
|---|---|---|
| 2026-09-06 | 「現象」は**オーナーの言葉に限らず、実機以外で見つかったものも受け入れる**（出どころを書く条件で） | [FB-17](./21_FB台帳.md#fb-17) を起こしたときに、ルール表の「現象＝オーナーの言葉」と食い違うと指摘された（コード品質レビュー）。FB-17 は FB-16 のレビューで**測って**出たもので、オーナーが実機で挙げたものではない。**この台帳が持つこと自体はオーナー判断で決まっている**ので、ルールの側を追随させた。**目的の行（「オーナーが実機で使って得た気づきを一元管理」）は変えていない**——それがこの台帳の主な役目であることに変わりはなく、広げたのは受け入れる入口だけ。**出どころを書く条件を付けた**のは、後から読んだときに「オーナーが困った」のか「測って分かった」のかで重みが違うため。別の置き場所も検討したが、[23](./23_技術改善バックログ.md) は挙動を変えない技術活動、[22](./22_要件バックログ.md) は未実装の要求（F-XXX）なので、**見た目という挙動の話**はどちらにも入らない |

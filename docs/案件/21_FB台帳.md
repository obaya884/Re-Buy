- 作成日: 2026-09-01
- 上位文書: [要件定義書](../仕様/12_要件定義書.md) §3（開発の現況）
- 本書は**オーナーが実機で使って出た指摘**の台帳。要求そのもの（F-XXX）は[要件バックログ](../案件/22_要件バックログ.md)、挙動を変えない技術活動は[技術改善バックログ](./23_技術改善バックログ.md)が持つ
- 運用ルールをなぜそう定めたかは本書に書かず、`log_21_FB台帳.md` へ日付順に積む（最初のエントリが出た時点で作る）

**挙動レベルの仕様判断が発生したら、直す前に仕様書群へ反映する**（CLAUDE.md）。本書は一行の要約に留める。

## 書式

**1 エントリ＝レーンの表の 1 行**。列は 6 つで、**すべて埋める**。

| 列 | 中身 |
|---|---|
| ID | `FB-XX` |
| タイトル | 指摘の名前 |
| 熟度 | **直す前にオーナーの仕様判断が要るか**（[要件バックログ](./22_要件バックログ.md) §書式 の判定表と同じ軸） |
| 内容 | 何が気になるかと、調べて分かった事実 |
| トリガ | **着手条件。ここを空にしない** |
| 参照 | 反映先の条項 |

- **セル内に `|` を書かない**
- レーンは `直す` / `見極め中` の 2 つ。**状態は行に持たず、どの表に置くかで表す**
- **完了したエントリは[closed_21_FB台帳.md](./closed_21_FB台帳.md)へ移す**（`## FB-XX タイトル（完了日）`＋対応・反映先の節に展開する）

## 現況

MVP（F-002〜F-013）の実装完了後、オーナーが実機で一周した最初の FB。**2026-09-01 に 12 件を起票**し、うち FB-01・FB-02 は同日中に直して[完了記録](./closed_21_FB台帳.md)へ移した。**番号はオーナーが挙げた順**。

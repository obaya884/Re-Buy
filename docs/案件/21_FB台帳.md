## 運用ルール

**1 エントリ＝ §一覧の 1 行 ＋ §詳細の 1 節。** 片方だけ手で足すと索引と本文が離れるので、`sh scripts/docs-check.sh` が対で持っているかを見る。

§一覧の列は 5 つで、**すべて埋める**。

| 列 | 中身 |
|---|---|
| ID | `FB-XX` |
| 起票日 | オーナーが挙げた日 |
| タイトル | 指摘の名前 |
| 詳細 | `#fb-xx` を指すリンク |
| 状態 | `未対応` ／ `完了 YYYY-MM-DD` ／ `対処不要 YYYY-MM-DD` |

§詳細の節は次の順で書く。**空にする項目は行ごと落とす。**

| 項目 | 中身 |
|---|---|
| 現象 | オーナーの言葉。**実機以外で見つかったものは出どころを書く**（レビューでの実測など） |
| 調べたこと | 実装や条項を当たって分かった事実。現象を読めば足りるなら落とす |
| 詰める点 | 直す前にオーナーと決めることの一覧。決まったら落とす |
| 決定 | 決まったこととその理由。決まるまでは書かない |
| 裏取り | 外部の出典に当たった記録。当たっていなければ落とす |
| 残したもの | 直したあとに残る不都合や、戻すときの手 |
| 関連 | 一緒に決めたい FB や、反映先の条項 |

- **セル内に `|` を書かない**（`docs-check` が列を数えられなくなる）
- 分類は `### 仕様判断待ち` ／ `### 着手待ち` の 2 つ。**どちらに置くかは「直す前にオーナー判断が要るか」で決める**
- **完了・対処不要にしたエントリは、状態更新と同じコミットで[完了記録](./closed_21_FB台帳.md)へ移す**（`sh scripts/ledger-move.sh FB-XX --status '完了 YYYY-MM-DD'`）

## 現況

MVP（F-002〜F-013）の実装完了後、オーナーが実機で一周した最初の FB。**2026-09-01 に 13 件を起票**し、FB-01・FB-02・FB-05 は同日中に、FB-03・FB-06・FB-12 は 2026-09-05 に片づけて完了記録へ移した。**2026-09-05 に FB-14・FB-15・FB-16 を追加**し、FB-15 は同日中に片づけた。**チップ列を触る 4 件（FB-07・08・11・13）は同じ場所を触るのでまとめて決め、FB-14・FB-10 とあわせて 2026-09-06 に片づけた**。**03 の見せ方を決める 2 件（FB-04・FB-09）も同日にまとめて片づけた**。**FB-16 も同日に片づき、起票した 16 件はすべて完了記録へ移った**。**FB-17 は FB-16 のレビューで測って出たもの**で、実機の指摘ではないがこの台帳が持つ。**オーナー起点でないエントリはこれが初**（FB-16 も調査中に出たが、提起したのはオーナー）。**FB-16 までの番号はオーナーが挙げた順**。

## 詳細

### FB-17

- 現象: **補助文字 `muted` が、載る面によっては [WCAG AA](https://www.w3.org/TR/WCAG21/#contrast-minimum) の 4.5:1 を割る。** [FB-16](./closed_21_FB台帳.md#fb-16) のレビューで測って出た（オーナーが実機で挙げたものではない）
- 調べたこと: いちばん低いのは**カゴ入り行の上の `muted`**（「前回 M/D」とカテゴリ・行き先タグ。`PoolScreen` が `ReBuyRowCard` の中に描く）で **2.65〜3.07**。**FB-16 の前から 6 通り中 4 通りが割っていた**（ライトが 3.82〜3.96、若葉ダークが 4.39）が、**藍ダークと柿ダークは FB-16 で 4.74 から初めて割った**。同じ理屈で割っている既存の組は他にもあり、**`muted` × 地（`page`）がライトで 3.98〜4.02**、**`accent` × `on-accent` が柿ライトで 4.64** と際どい。余裕がある組は `ink` 系（`page`・`card`・`accent-soft` のいずれの上でも 6.00 以上）
- 詰める点: **`muted` を濃くするか**（全画面に効く）、**カゴ入り行だけ補助文字を変えるか**（一覧の中で行ごとに濃さが変わる）、**AA を目標にするかどうか**（補助文字は「読めなくても致命でない」情報という整理もありうる）。トークンを足す道は 3 パレット × 明暗で 6 値増える（C-4）
- 関連: [13](../仕様/13_画面定義書.md) §5。**FB-16 で置いた上下の網は `ink` までしか見ていない**——`muted` を含めるとこの案件を決める前に落ちるので、意図して範囲外にした

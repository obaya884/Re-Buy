## 運用ルール

**1 エントリ＝ §一覧の 1 行 ＋ §詳細の 1 節。** 片方だけ手で足すと索引と本文が離れるので、`sh scripts/docs-check.sh` が対で持っているかを見る。

§一覧の列は 5 つで、**すべて埋める**。

| 列 | 中身 |
|---|---|
| ID | `FB-XX` |
| 起票日 | オーナーが挙げた日 |
| タイトル | 指摘の名前 |
| 詳細 | `#fb-xx` を指すリンク |
| 状態 | `未対応` ／ `完了 YYYY-MM-DD` ／ `対処不要 YYYY-MM-DD` |

§詳細の節は次の順で書く。**空にする項目は行ごと落とす。**

| 項目 | 中身 |
|---|---|
| 現象 | オーナーの言葉 |
| 調べたこと | 実装や条項を当たって分かった事実。現象を読めば足りるなら落とす |
| 詰める点 | 直す前にオーナーと決めることの一覧。決まったら落とす |
| 決定 | 決まったこととその理由。決まるまでは書かない |
| 裏取り | 外部の出典に当たった記録。当たっていなければ落とす |
| 残したもの | 直したあとに残る不都合や、戻すときの手 |
| 関連 | 一緒に決めたい FB や、反映先の条項 |

- **セル内に `|` を書かない**（`docs-check` が列を数えられなくなる）
- 分類は `### 仕様判断待ち` ／ `### 着手待ち` の 2 つ。**どちらに置くかは「直す前にオーナー判断が要るか」で決める**
- **完了・対処不要にしたエントリは、状態更新と同じコミットで[完了記録](./closed_21_FB台帳.md)へ移す**（`sh scripts/ledger-move.sh FB-XX --status '完了 YYYY-MM-DD'`）

## 詳細

### FB-04

- 現象: 「行き先が存在しない場合に『今日はどこへ？』→『2 件で開始』が少し違和感ある」。行き先を 1 つも作っていないと全件モードになり、問いと答えが噛み合わない
- 詰める点: 全件モードのときだけ見出しを変えるか、別の見せ方にするか
- 関連: [13](../仕様/13_画面定義書.md) 画面 03。**[FB-09](#fb-09) と同じ「03 でどこでも買えるものをどう見せるか」の話なので一緒に決める**

### FB-09

- 現象: 「『今日はどこへ？』でどこでも（行き先なし）は一緒に入っていることが＋1 などの暗黙でしか分からない点が少し違和感ある」
- 詰める点: 行に添えるか、注記を置くか、別の見せ方にするか
- 関連: [13](../仕様/13_画面定義書.md) 画面 03。**[FB-04](#fb-04) と一緒に決める**

### FB-10

- 現象: 「気づいたものの検索をかなカナくらいは対応したい。漢字どうするかはまた検討」。画面 05 は「ひらがな・カタカナの同一視はしない」と明記して実装もそのとおり
- 決定: **かな・カナに加えて全角・半角も同一視する**（オーナー判断 2026-09-01）。漢字・読みは別途検討。実装量はほぼ変わらず、「打ち方の揺れで見つからない」がまとめて消える
- 関連: [13](../仕様/13_画面定義書.md) 画面 05。実装は `AddNoticedSheetUiState` の当たり判定 1 か所

### FB-16

- 現象: 「そもそもパレットの色指定を見直すべきか別件で検討が必要そう」。[FB-07](./closed_21_FB台帳.md#fb-07) の調査中にオーナーが提起
- 調べたこと: 選択面 `accent-soft` と、その下に敷かれる面とのコントラスト比を測った。**01 の地（`page`）の上ではライトの 3 パレットが 1.02〜1.05:1**（1.00 が同色）、ダークが 1.45〜1.54:1。**シートの面（`card`）の上ではライトが 1.18〜1.22:1、ダークが 1.16〜1.18:1** で、**明暗でどちらがましかが逆転する**。WCAG が UI 部品の状態に求める 3:1 にはどの組み合わせも届かない。`accent-soft` は §5 で「選択面・カゴ入り行」の 2 役を兼ねているので、**チップのために濃くすると一覧のカゴ入り行も濃くなる**
- 詰める点: `accent-soft` を濃くするか、**選択面とカゴ入り行でトークンを分けるか**。分けると 3 パレット × 明暗で 6 値増える。地（`page`）側を動かす道もあるが、[FB-01](./closed_21_FB台帳.md#fb-01) で「地は 1 段」と決めたところに関わる
- 関連: [13](../仕様/13_画面定義書.md) §5（配色トークン）。**[FB-07](./closed_21_FB台帳.md#fb-07) は ✓ を足して色に頼らない形にしたので、この案件が動かなくても実害は出ない**——色を見直すかは別の判断
